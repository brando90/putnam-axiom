Why this benchmark exists

Advanced reasoning needs stress tests that are hard to memorize.

Putnam-AXIOM packages problems from the William Lowell Putnam Mathematical Competition into an evaluation suite for model reasoning. The repository includes the original benchmark data, variation datasets, and evaluation code for running Hugging Face models through a VLLM-backed pipeline.

The static split gives a stable target for comparison. The functional variation split tests whether a model can preserve the proof strategy when symbols, constants, or problem structure change. That combination is the core of the release: one benchmark for historical difficulty, and one for controlled reasoning robustness.

Functional variation design

One original problem becomes five controlled tests.

Putnam-AXIOM Variations v4 contains 100 seed problems and 500 generated test items. Each seed contributes five variants, letting evaluators ask a sharper question: does the model understand the invariant method, or did it only recognize surface form?

The current v4 test set includes variable substitutions, constant changes, and a small set of more significant perturbations.

What the benchmark covers

Putnam-AXIOM mixes geometry, number theory, algebra, and analysis.

Evaluation

Run a model against originals or variations.

The repository exposes a Python evaluation script. Point --data_dir at the original file or one of the variation JSON files, choose the prompt format, and pass a VLLM-compatible Hugging Face model name.

Example command 
python putnam-axiom/src/eval.py \
  --data_dir putnam-axiom/data/Putnam_AXIOM_Original_v3.json \
  --model_name meta-llama/Meta-Llama-3-8B \
  --output_dir results/llama3-putnam-original
--data_dir

Original or variation JSON dataset path.

--prompt_name

Prompt adapter such as general, mistral, llama, or gemma.

--repeat_eval

Number of repeated generations for robustness checks.

--max_tokens

Maximum generation length for proof-style completions.
